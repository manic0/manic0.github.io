kali上安装Hermes Agent

1、安装前配置代理

vim ~/.zshrc

source ~/.zshrc

env | grep -i proxy

2、安装

3、配置Hermes Agent

3.1 自动进入配置界面，选择第一个

3.2 选择API提供商，这里选择自定义

3.3 填写URL：https://ai.manic.com.cn。复制API密钥到API key。key不会显示在终端

3.4 选择API兼容模型，这里1-4都可以选择，我选择1

3.5 选择模型，我选择了claude-opus-4-6

3.6 这里我都默认回车了

3.7 配置通讯软件，选择了微信，输入14 回车，然后再次回车

3.8 输入Y回车后，使用浏览器访问URL，使用微信扫描二维码。（我一开始使用的是鸿蒙系统的微信，但是一直加载状态。然后用了测试机微信扫的二维码成功了。）

3.9 扫完以后会询问你 消息授权配置，直接默认即可

3.10 这里都是Y回车，然后弹出网关在后台运行的方式默认即可

3.11 问启动服务吗，输入y启动。

3.12 输入hermes命令启动服务

4、微信配对授权

4.1 给微信机器人发消息，会得到hermes pairing approve weixin PFXXXXXX

4.2 将内容发送到聊天框，就会得到配对成功的提示。

4.3 可以跟机器人对话了

至此，Hermes Agent 微信通讯就配置好了！
