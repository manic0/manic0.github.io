环境检查

docker --version
👉 查看 Docker 是否安装成功及版本信息

dpkg -l | grep docker
👉 检查系统中安装的 Docker 相关包（engine / cli / containerd 等）

containerd --version
👉 查看底层容器运行时 containerd 版本（K8s 依赖）

docker-compose version
👉 检查是否安装 docker-compose（用于多容器编排）

systemctl status docker
👉 查看 Docker 服务是否正在运行
